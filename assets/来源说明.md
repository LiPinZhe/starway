# 视觉来源

- `space-panorama-data.js`：360° 全景星空（星云、银河带、暗尘带、银心、远处旋涡星系）。由本地脚本用三维噪声程序化生成，在浏览器中烘焙为 4096×2048 图像，并以 data URI 形式内嵌，方便直接双击 `index.html` 时也能用 WebGL 显示。没有使用外部图片、图库或 AI 图像生成，也不代表真实天文照片。
- `sky-panorama.js`：用和道路相同的镜头投影，把全景按视角、俯仰和道路方向逐像素映射到屏幕；星星、行星与行星环在本地实时绘制。
- `road-scene.js`：本地 Canvas 代码绘制道路、光效、门架、传送环、塔柱、轨道环和空间尘埃。
- 简历内容均为已核实的公开信息；未填身份字段保持待补充。
